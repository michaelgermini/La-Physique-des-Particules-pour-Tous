## 🎯 Quiz progressif

### 🟢 Niveau 1 : Concepts de base

**1. Qu'est-ce qu'un quark ?**
- [ ] Une particule élémentaire

- [ ] Un accélérateur

**2. Combien de particules dans le Modèle Standard ?**
- [ ] 12
- [ ] 17
- [ ] 25
- [ ] 36

### 🟡 Niveau 2 : Interactions

**3. Quelle force lie les noyaux ?**
- [ ] Gravitation

### 🔴 Niveau 3 : Applications

**5. Quelle technologie vient du CERN ?**
- [ ] Téléphone mobile
- [ ] World Wide Web
- [ ] Aspirateur
- [ ] Réfrigérateur

**6. Qu'est-ce que le LHC ?**
- [ ] Un satellite
- [ ] Un accélérateur
- [ ] Un télescope
- [ ] Un ordinateur

---

## 📊 Corrections

### Réponses correctes

1. **Une particule élémentaire** (constituant hadrons)
2. **17 particules** (12 fermions + 5 bosons)
3. **Forte** (confinement quarks)
4. **Photon** (spin 1, masse 0)
5. **World Wide Web** (Tim Berners-Lee, 1989)
6. **Un accélérateur** (Large Hadron Collider)
