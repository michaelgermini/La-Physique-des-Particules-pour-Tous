## 📐 Échelle de Planck

### 🧮 Constantes fondamentales

**Longueur de Planck :**
```
lp = √(ℏ G / c³) ≈ 1.62 × 10^-35 m
```

**Énergie de Planck :**
```
Ep = √(ℏ c⁵ / G) ≈ 1.22 × 10^19 GeV
```

**Température de Planck :**
```
Tp = Ep / k_B ≈ 1.42 × 10^32 K
```
